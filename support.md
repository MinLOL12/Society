### Support & Issues

Found a bug with stats not saving, wrong percent, or HUD not showing?

- Open an issue: https://github.com/MinLOL12/Society/issues
- Include:
  - Your GD version (2.2074 etc)
  - Geode version
  - Level type (online ID or editor name)
  - Screenshot of HUD / console log (`geode/logs/`)
  - Your save file: `<GD>/geode/mods/minlol.progressive-stats/save/level_stats.json`

Tips:
- Make sure HUD is enabled in mod settings (Geode mod menu).
- If HUD overlaps, change position to Bottom or Custom.
- Practice stats are off by default — enable `Track Practice Mode` if you want them counted.
- To reset session, exit level or toggle `Reset Session on Exit`.

Discord: you can find me in Geode Discord #support.
